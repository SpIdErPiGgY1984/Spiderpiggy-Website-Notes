# Changelog

## 1.0.0 — Initial public release (25 October 2026)
- Popup notes and floating draggable sticky notes.
- Optional automatic display after page reload, with website-specific permissions.
- Optional all-sites permission flow, explicitly requested by the user.
- Independent notes, titles and colors for domains and individual pages.
- Persisted collapsed state; hide color and title-edit controls in collapsed mode.
- Responsive layout for smaller displays.
- Local storage, searchable manager, JSON import/export, Dutch/English localization, light/dark theme.
