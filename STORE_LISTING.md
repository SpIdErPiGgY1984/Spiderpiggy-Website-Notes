# Suggested AMO listing

**Name:** Spiderpiggy Website Notes

**Short description (EN):** Private notes for every website or page, with draggable sticky notes, custom titles, colors and local backups.

**Short description (NL):** Privénotities per website of pagina, met verplaatsbare sticky notes, eigen titels, kleuren en lokale back-ups.

## Description (English)

Keep practical notes right where you need them. Spiderpiggy Website Notes allows you to save a note for an entire website or one specific page and open it in a lightweight toolbar popup or a movable sticky note on the page.

Features:
- Notes per website or page, saved locally in Firefox.
- Optional automatic display after refreshing a website.
- Custom titles and seven colors for each website or page.
- Compact sticky notes that can be minimized, moved and restored.
- Find and edit notes in a searchable overview.
- Export and import backups in JSON format.
- Dutch and English user interface, light and dark themes.
- No accounts, advertising, trackers, cloud sync or data transmission.

Permissions: The extension requests access to websites only when you enable automatic display on a website or explicitly select access to all websites. Automatic display remains opt-in on individual websites.

Do not store passwords or confidential data in notes; local notes are not encrypted.

## Beschrijving (Nederlands)

Bewaar handige notities op de plek waar je ze nodig hebt. Spiderpiggy Website Notes laat je een notitie bewaren voor een volledige website of voor een afzonderlijke pagina. Open de notitie via een compact Firefox-venster of als verplaatsbare sticky note op de website zelf.

Functies:
- Notities per website of pagina, lokaal opgeslagen in Firefox.
- Optioneel automatisch tonen na het vernieuwen van een website.
- Zelfgekozen titels en zeven kleuren per website of pagina.
- Compacte sticky notes die je kunt verplaatsen en minimaliseren.
- Een doorzoekbaar overzicht om notities te beheren.
- JSON-back-ups exporteren en importeren.
- Nederlands en Engels, met een licht en donker thema.
- Geen account, advertenties, tracking, cloudopslag of verzonden gegevens.

De extensie vraagt alleen website-toegang wanneer je automatische weergave voor een website inschakelt of zelf kiest voor toegang tot alle websites. Automatische weergave moet nog steeds per website worden ingeschakeld.

Bewaar geen wachtwoorden of vertrouwelijke gegevens in de notities. De lokale opslag is niet versleuteld.
